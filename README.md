🚀 Progetto Finale Hackademy - Presto.it
Benvenuti nel mio progetto finale realizzato durante il Master di Aulab.
Si tratta di una piattaforma di annunci (tipo Subito.it) sviluppata con un team di 4 persone.

🛠 Tecnologie utilizzate:
Framework: Laravel (PHP)

Frontend: Tailwind CSS & Blade

Database: MySQL

👩‍💻 Il mio contributo:
Mi sono occupata principalmente della parte Frontend e della User Experience, curando il design responsive con Tailwind e la gestione delle viste Blade, unendo le mie competenze di Web Design (Infobasic) con la programmazione.
